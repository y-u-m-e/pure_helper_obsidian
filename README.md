# Pure Tracker Obsidian Plugin

Obsidian-native pure build tracker with workbook import, exclusion recompute, data-sheet editing, and flow-style dashboard view.

## Files required by Obsidian/BRAT

- `manifest.json`
- `main.js`
- `styles.css`
- `versions.json`

## Release asset checklist

When creating a GitHub release for BRAT:

1. Tag version should match `manifest.json` version.
2. Upload the four files listed above as release assets.
