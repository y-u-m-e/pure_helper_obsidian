# Pure Tracker Dev Tools

Developer-only helper scripts for bootstrapping and verification.

## Scripts

- `seed-phase1-data.js` - imports workbook goals and regenerates derived quest/diary outputs.
- `verify-phase1.js` - runs pure rule-engine assertions and writes `verification_snapshot.json`.

## Usage

- `node ".obsidian/plugins/pure-tracker/dev-tools/seed-phase1-data.js"`
- `node ".obsidian/plugins/pure-tracker/dev-tools/verify-phase1.js"`
